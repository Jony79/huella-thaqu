# Contenido de la app

`areas.json` se arma desde las fichas de Scouts de Argentina:

- Salud y bienestar (azul)
- Habilidades para la vida (naranja)
- Ambiente (verde)
- Paz y desarrollo (violeta)

`insignias.json` define el rombo: Sur arriba, Oeste a la derecha, Norte abajo, Este a la izquierda.

Para regenerar el catálogo: `python content/build_areas.py`.
